## Convencion de nombres

- Carpeta: `[slug-funcionalidad]/` — misma carpeta que en `funcionalidades/`
- Documento: `[YYYY-MM-DD]_[tipo]_[titulo-breve].md`
  - Tipo: `fix` o `hotfix`
  - Ejemplo: `2026-03-04_hotfix_error-400-csrf.md`
  - Ejemplo: `2026-03-10_fix_validacion-dni-vacio.md`

Cada correccion es un archivo separado. No editar archivos anteriores.
